# HMM Market Regime Classification

Классификация рыночных режимов `long` и `short` на часовых данных фьючерса на индекс МосБиржи с использованием моделей Hidden Markov Model.

## Цель проекта

Цель проекта — определить текущий рыночный режим на основании динамики цены, объёма, волатильности и структуры часовых свечей.

Задача сформулирована как бинарная классификация:

- `long` — восходящий рыночный режим;
- `short` — нисходящий рыночный режим.

Для каждого класса обучается отдельная `GaussianHMM`. Классификация выполняется сравнением нормализованных log-likelihood двух моделей на заданном окне наблюдений.

## Формирование классов

Режимы `long` и `short` формируются алгоритмически на основании локальных экстремумов цены.

Локальный минимум начинает режим `long`, а локальный максимум — режим `short`. После обнаружения экстремума метка распространяется до следующей смены режима.

## Модель

Используется классификатор на основе двух моделей `GaussianHMM`:

- первая HMM обучается на последовательностях режима `long`;
- вторая HMM обучается на последовательностях режима `short`;
- для каждого окна рассчитывается нормализованный log-likelihood;
- выбирается класс с большей вероятностью наблюдаемой последовательности.

Для обучения используются только непрерывные последовательности достаточной длины. Перед обучением проверяются количество наблюдений, наличие обоих классов и сходимость HMM.
